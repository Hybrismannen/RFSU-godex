## RAMx logic

RAMx is a bounded capacity model, not a rigid activity-by-activity timesheet architecture.

Working planning envelope for the proposal:
- strategic calculation rate: SEK 1,000/hour excluding VAT;
- total available budget ceiling: SEK 150,000 including VAT;
- equivalent maximum capacity at that rate: 120 hours.

The exact proposal offer may use less than the ceiling.

## Control model

For each control cycle:

**Committed → Used → Forecast → Remaining → Risk to completion**

Scope expansion must be evaluated against the remaining RAMx capacity before being accepted.
