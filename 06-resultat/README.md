# 06 — Resultat

Den här delen aktiveras när uppdraget går in i genomförande.

Här publiceras endast stabila och godkända resultat som är meningsfulla för extern läsning, exempelvis:
- återkommande teman;
- goda exempel;
- hinder;
- möjliggörande strukturer;
- överförbarhetsinsikter;
- rekommendationer.

Arbetsanteckningar och rådata publiceras inte här.
