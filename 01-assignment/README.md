# 01 — Assignment

Purpose: freeze the commissioning logic before consultant design is layered onto it.

## Required artifacts

### 01 Original brief
Canonical source or link to RFSU's assignment description.

### 02 Requirements extraction
A requirement matrix separating:
- explicit client requirement;
- interpretation;
- consultant proposal.

### 03 Assignment process map
The assignment as described by RFSU:

**Identify three clinics → Examine practice + structural conditions → Analyse each case → Compare cases → Translate to transferable knowledge → Report + presentation**

### 04 Constraints
Binding or planning constraints:
- three clinics;
- adult/post-youth-clinic population;
- holistic, multidisciplinary and person-centred care;
- key-person interviews/focus groups;
- structural document analysis;
- report max 30 pages;
- report deadline;
- final completion date;
- total budget ceiling.

## Design rule

No consultant-created method should be represented as if it were an RFSU requirement.
