# 02 — Proposal

Purpose: convert the assignment brief into a credible, bounded and cost-aware proposal.

## Proposed structure

1. **Proposal strategy**
   - bid position
   - value proposition

2. **Consultant profile**
   - consultant profile
   - relevant experience
   - reference cases

3. **Method & work process**
   - assignment design
   - process map
   - methodology

4. **RAMx budget**
   - RAMx model
   - internal capacity model
   - proposal budget

5. **Timeline**
   - delivery corridor
   - key milestones

6. **Selection approach**
   - All → Gate → Relevance → Palette → RFSU dialogue → Three cases
   - gate framework
   - palette framework

7. **Risk & quality**
   - scope control
   - quality assurance
   - data/privacy considerations

8. **Final submission**
   - final proposal files

## Budget working premise

General consulting rate: SEK 1,200/hour excluding VAT.

For this proposal, a simplified strategic RAMx calculation may use SEK 1,000/hour excluding VAT.

At the full budget ceiling:
- SEK 120,000 excluding VAT
- SEK 150,000 including VAT
- 120 RAMx hours at SEK 1,000/hour excluding VAT

The final proposal does not need to allocate every hour rigidly to a fixed activity. RAMx should protect quality and adaptability inside a bounded capacity envelope.
