# 05 — Lägesbild

Den här delen används för korta, tydliga uppdateringar om var arbetet befinner sig.

## Nuvarande läge

**Fas:** Förberedelse inför proposal/anbud.

### Klart
- uppdragets tids- och budgetram har lästs om och preciserats;
- första processbilden har justerats mot uppdragsbeskrivningen;
- ett första nationellt mottagningslandskap har börjat kartläggas;
- urvalslogiken Alla → Gate → Relevans → Palett är etablerad;
- grundläggande analyslogik är etablerad.

### Under arbete
- fördjupad mottagningskartläggning;
- proposal-design;
- metod- och tidsbudget;
- formulering av uppdragsgivarvänliga underlag.

### Öppna frågor
- vilka typer av mottagningar RFSU särskilt vill ha med i den slutliga paletten;
- hur mycket fysisk närvaro som är önskvärd respektive möjlig inom budget;
- vilka strukturella underlag som kan göras tillgängliga från de valda mottagningarna.
