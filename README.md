# RFSU Godex

Operational repository for the RFSU consultancy assignment on good practice for equitable SRHR care.

## Repository purpose

This repository documents the assignment from proposal design through delivery and, where appropriate, a sanitized retrospective case. It is designed to preserve traceability between:

**Assignment requirements → intelligence → clinic landscape → method design → fieldwork → analysis → report → handover → case learning**

## Current status

**Phase:** Proposal / pre-award  
**Repository status:** Public  
**Data rule:** No personal data, interview raw data, confidential client material, unpublished clinic material, or sensitive operational information may be stored in this public repository.

## Core analytical logic

**Structural conditions → Actual practice → Working mechanism → Barriers/enablers → Transferability → Recommendation**

## Clinic selection logic

**All → Gate → Relevance → Palette → Dialogue with RFSU → Three cases**

The repository does not pre-select the three clinics. The selection architecture is designed to give RFSU a transparent and useful palette for joint discussion.

## Assignment frame

- Three clinics for sexual health serving people above youth-clinic age
- Holistic, multidisciplinary and person-centred practice
- Interviews and/or focus groups with key staff
- Analysis of structural conditions, including relevant regional guidelines and agreements
- Cross-case analysis of good practice and barriers
- Assessment of transferability to similar services
- Accessible report, maximum 30 pages
- Presentation to RFSU and participating clinics
- Report within three months from start and no later than 29 January 2027
- Assignment completed no later than 19 February 2027
- Total budget ceiling: SEK 150,000 including VAT

## Public/private boundary

This repository is currently public. Public material may include:
- proposal architecture;
- publicly sourced clinic landscape material;
- generic method frameworks;
- sanitized process diagrams;
- final public deliverables where publication is authorized;
- retrospective case material that contains no confidential or personal information.

Material that must remain outside this public repository includes:
- interview recordings or transcripts;
- personal/contact data;
- unpublished clinic documents;
- confidential agreements or internal client documents;
- sensitive operational notes;
- identifiable quotes before explicit clearance;
- any material covered by confidentiality or data-protection obligations.

See `00-repository-control/data-privacy-boundaries.md`.

## Status principle

A file should make clear whether it is:
- **SOURCE** — supplied or published source material;
- **INTERPRETATION** — analysis derived from sources;
- **PROPOSAL** — consultant-designed method or recommendation;
- **DECISION** — confirmed project decision;
- **ARCHIVE** — superseded material retained for traceability.
