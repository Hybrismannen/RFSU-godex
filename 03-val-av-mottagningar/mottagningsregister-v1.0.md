# Mottagningsregister v1.0

**Senast uppdaterat:** 21 september 2026

Det här registret samlar de mottagningar som hittills har identifierats som möjliga eller analytiskt intressanta för uppdraget. Det är ett **arbetsregister**, inte en ranking och inte ett påstående om att varje svensk verksamhet finns med.

Syftet är att skapa ett tillräckligt brett och spårbart underlag för:

**Alla → Gate → Relevans → Palett → Dialog med RFSU → Tre mottagningar**

När offentlig information inte räcker för att avgöra om en mottagning uppfyller uppdragets kriterier markeras det som något som behöver verifieras.

## Hur registret ska användas

Registerpositionerna beskriver bara **relevans för det här uppdraget**. De är inte kvalitetsomdömen om verksamheterna.

Nästa steg är trestegsurvalet: Gate → Relevans → Palett.
