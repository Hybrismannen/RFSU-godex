# Urvalskriterier

Urvalet sker i två steg.

## Steg 1 — Gate

En mottagning behöver vara relevant för själva studieobjektet.

| Fråga | Bedömning |
|---|---|
| Finns en tydlig vuxenfunktion efter ungdomsmottagningsåldern? | Ja / Oklart / Nej |
| Är sexuell hälsa ett kärnuppdrag? | Ja / Oklart / Nej |
| Arbetar verksamheten holistiskt? | Ja / Oklart / Nej |
| Arbetar flera professioner tillsammans? | Ja / Oklart / Nej |
| Finns stöd för ett personcentrerat arbetssätt? | Ja / Oklart / Nej |

Gate säger inget om kvaliteten på vården. Den avgör bara om mottagningen är relevant för just detta uppdrag.

## Steg 2 — Relevans

När en mottagning passerat Gate beskriver vi vilken typ av kunskap den kan bidra med.

Exempel på relevansdimensioner:
- organisationsform;
- styrmodell;
- plats i vårdkedjan;
- SRHR-bredd;
- professionell konfiguration;
- access;
- jämlikhetsprofil;
- strukturell spårbarhet;
- överförbarhet;
- praktisk genomförbarhet.

Ingen totalsumma eller ranking används.
