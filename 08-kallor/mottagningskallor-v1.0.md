# Källregister — mottagningslandskap v1.0

**Kontrollerat:** 21 september 2026

Primära länkar för mottagningskartläggningen finns i [Mottagningsregister v1.0](../03-val-av-mottagningar/mottagningsregister-v1.0.md).

Källhierarki:
1. officiell regional eller vårdgivarsida;
2. 1177 kontaktkort;
3. officiella styr-/uppdragsdokument;
4. RFSU:s eget underlag;
5. sekundärkällor endast som orientering.

Offentlig webbinfo används för screening. Uppgifter om exempelvis personcentrering eller faktisk samverkan mellan professioner verifieras i dialog när webbunderlaget inte räcker.
