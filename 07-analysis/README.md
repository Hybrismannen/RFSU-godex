# 07 — Analysis

Purpose: convert three cases into cross-case knowledge relevant to RFSU's assignment.

## Analysis sequence

1. Within-case analysis
2. Cross-case comparison
3. Good practice
4. Barriers
5. Enabling conditions
6. Transferability
7. Recommendations

## Core question

The report should not stop at:

**What does Clinic A, B and C do?**

It should move toward:

**What works? → Why does it work? → What enables it? → What constrains it? → What is context-bound? → What is transferable? → What should change?**

## Traceability requirement

Every final recommendation should be traceable back to:
- one or more case findings;
- relevant structural conditions;
- identified mechanisms;
- explicit transferability reasoning.

The cross-case synthesis is the primary analytical product. The three case descriptions are evidence bases, not the final storyline.
