# 05 — Method Design

Purpose: define a disciplined method that answers the assignment without over-designing it.

## Core architecture

Two evidence tracks are examined separately and then brought together.

### Structural track

- formal remit
- regional guidelines
- agreements/commissioning
- organisational placement
- governance
- mandates
- resources
- referral/access pathways
- other enabling or constraining structures

### Practice track

- actual working methods
- professional roles
- multidisciplinary collaboration
- routes into care
- assessment
- support/treatment
- follow-up
- adaptations to individual need
- barriers encountered in practice

## Synthesis logic

**Structural conditions**
→ **Actual practice**
→ **Working mechanism**
→ **Barriers & enabling conditions**
→ **Transferability**
→ **Recommendation**

## Planned sub-areas

1. Analytical framework
2. Structural track
3. Practice track
4. Interview/focus-group design
5. Comparison framework
6. Transferability framework
7. Quality, ethics and data handling

## Design discipline

The assignment is not automatically:
- a patient study;
- an impact evaluation;
- a national prevalence study;
- a full system evaluation.

Additional methods must earn their place by improving the assignment's answer inside the available RAMx, timeline and budget.
