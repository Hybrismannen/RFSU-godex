# 06 — Fieldwork

This directory defines fieldwork structure only.

Because this repository is public, **raw fieldwork data must not be stored here**.

## Case structure after award and final selection

```text
clinic-A/
├── 00-case-profile.md
├── 01-structural-material/
├── 02-interviews-focus-groups/
├── 03-working-notes/
├── 04-case-analysis/
└── 05-case-summary.md
```

The same structure applies to clinic B and clinic C.

## Public-repository restriction

Folders for interviews/focus groups and working notes may contain only:
- generic templates;
- data-management instructions;
- sanitized summaries approved for repository use.

Recordings, transcripts, personal data and confidential material belong in approved protected storage outside GitHub.
