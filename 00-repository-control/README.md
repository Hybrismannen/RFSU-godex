# 00 — Repository Control

This directory controls the repository itself.

## Contents

- `repository-map.md` — canonical directory architecture
- `data-privacy-boundaries.md` — what may and may not be stored here
- `naming-versioning-convention.md` — file naming and version rules
- `decision-log.md` — major project/repository decisions
- `source-ledger.md` — source provenance register
- `project-status.md` — current phase and next controlled operation

## Control principle

Repository structure should follow the assignment lifecycle and preserve traceability. No directory exists merely for storage; each has an operational purpose.
