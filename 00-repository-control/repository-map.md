## Lifecycle logic

1. **Assignment** freezes what RFSU actually asks for.
2. **Proposal** translates that brief into a credible delivery architecture.
3. **Intelligence** provides bounded contextual knowledge before delivery work.
4. **Clinic Landscape** builds the selection field: All → Gate → Relevance → Palette.
5. **Method Design** defines how structural conditions and practice are studied.
6. **Fieldwork** holds case execution structure.
7. **Analysis** transforms three cases into cross-case learning.
8. **Report** produces the formal deliverable.
9. **Handover** returns findings and closes the commission.
10. **Project Control** maintains RAMx, milestones, risks and deliverables.
11. **Case Study** preserves reusable, sanitized learning from the assignment.
